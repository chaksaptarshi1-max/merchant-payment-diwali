# Merchant Payment – The Hidden Diwali Surprise

This repository contains a static GitHub Pages website and a print-ready QR standee for a playful merchant payment simulation.

## Files

- `index.html` — responsive payment simulation page with animated loading state, festive surprise reveal, replay button, and optional sound/vibration toggles.
- `standee.html` — A4 print-ready standee in blue and white with a genuine QR code that points to the public GitHub Pages URL.
- `README.md` — instructions for publishing and printing.

## Publishing on GitHub Pages

1. Push this repository to GitHub.
2. Open the repository in GitHub.
3. Go to: Settings → Pages.
4. Under "Build and deployment", choose:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
5. Save the setting.
6. GitHub generates a public URL like:
   `https://chaksaptarshi1-max.github.io/merchant-payment-diwali/`

## Printing the standee

1. Open `standee.html` in a browser.
2. Use the browser's print dialog.
3. Select A4 portrait size.
4. Keep background graphics enabled if the browser offers that option.
5. Print the page on standard A4 paper.

## Notes

- The payment flow is a playful demo only.
- No real payment gateway, UPI ID, OTP, PIN, or card details are involved.
- The site is static and works without a backend.
- Sound is off by default.
- Reduced motion is supported.

## Local preview

Open `index.html` or `standee.html` in a browser to inspect the pages before publication.

## Important

This repository is not yet deployed until GitHub Pages is enabled in the repository settings and the live URL has been verified in a browser.
